# 链 X ｜ 2026-11-14 ｜ 优化轮 R11 ｜ 渐变背景：可见度与对比度在同一个旋钮上

> 里程碑：M0–M7 之后的**第六轮系统优化**（R11）
> 关联需求：用户一句"登录进去之后背景颜色太过单调，可以尝试用适当的渐变色来美化背景"，
> 并要求更新文档与 GitHub
> 关联文件：`frontend/src/styles.css`、`frontend/src/views/WelcomeView.vue`、`.build/check_r11.py`、
> `.build/measure_r11.py`

---

## X.1 目标

| 需求 | 表面看 | 实际牵连 |
| --- | --- | --- |
| 登录后背景太单调，用渐变美化 | 把 `--c-bg` 换成 `linear-gradient` | 渐变让"bg"从**一个值变成一段取值范围**，R10 那套"三底验算"的对比度结论不再直接可用；光晕叠上底纹的**合成色**比任何停靠点都深，是验算覆盖不到的第四种背景 |

**这一轮的核心判断**：渐变的可见度与文字对比度**拧在同一个旋钮上**——底色越深渐变越看得见，
dim 文字越读不清。所以每一档深浅都必须实算，不能靠截图"看着还行"。

## X.2 我发给 AI 的完整 Prompt

> @image#1:Clipboard_Screenshot.png 登录进去之后背景颜色太过单调，可以尝试用适当的渐变色来美化背景，完成后更新需要迭代的文件，更新github仓库

（截图：登录后的工作台，四张白卡浮在一片均匀的浅灰绿上）

### 我对 Prompt 的理解

"太单调"指的不是没有颜色，而是**没有层次**——截图里背景与卡片只有一个对比度，
视线没有任何引导。所以解法不是"加颜色"，是"加渐变带来的空间层次"；
且上一轮（R10）刚立了"对比度必须算"的规矩，这轮改背景等于动了验算的地基，必须同步扩。

## X.3 AI 的关键输出与我的取舍

| 方案 | 取舍 | 理由 |
| --- | --- | --- |
| 大面积品牌色渐变（青碧 135° 铺满） | ❌ 否 | R10 已有结论：大面积饱和色在浅色界面里显脏 |
| 只加深 radial 光晕（alpha 0.07 → 0.15+） | ❌ 否 | 实算 dim 对光晕合成底只剩 4.2 左右；可见度全押在光晕上必然压过可读性 |
| **一层极浅斜向底纹 + 三处低透明度光晕（采纳）** | ✅ | 可见度交给停靠点渐进（`#edf5f2 → #f4f8f7 → #eef5f2`），光晕只做方向引导；`background-attachment: fixed` 保证长页滚动时背景稳定 |
| dim 对光晕合成底 4.49:1 → 再降光晕 alpha | ❌ 否 | alpha 压到合成底达标的 0.013 时肉眼已经看不见，"美化"名存实亡 |
| **欢迎页 eyebrow 由 dim 改 `--c-text-2`（采纳）** | ✅ | 它是全站唯一直接坐在渐变上的文字；text-2 同位置 4.98–5.31:1，语义也更对（眉题是"次级"不是"弱化"） |

## X.4 我的判断与修改

1. **最深停靠点必须实算下限**：node 一段脚本扫出 `#eaf2ee` 上 dim 4.43、`#ecf4f1` 上 4.51、
   `#edf5f2` 上 4.55——最终取 `#edf5f2` 留余量，并把"#ecf4f1 是下限"写进 styles.css 注释与验收断言。
2. **合成底是 R10 验算体系的盲区**：`radial` 叠 `linear` 的结果（如内容区左上 `(227,240,236)`）
   比最深停靠点（`#edf5f2`，亮度 0.905）深了 0.058。R10 的"三底验算"没有覆盖这种叠加态，
   所以规矩改成两条：停靠点层验 dim、合成底层验 text-2（内容带里没有 dim，全在白卡里）。
3. **验收判据沿用 R10 的"画出来了"**，且新增**覆盖层**断言（`.app`/`.main`/`.content` 必须透明）——
   令牌、对比度全对但外壳铺了底色，渐变照样看不见，这类失败前一层断言抓不到。

## X.7 遗留与已知限制

- **C-18（新增）**：`background-attachment: fixed` 在 iOS Safari 不可靠，移动端渐变未验收；
  桌面三浏览器正常。对比度规矩不依赖附着方式，`fixed` 失效时只是观感退化。
- 渐变是全局令牌，落地页与内页共享；若未来要"内页渐变、落地页纯色"，
  得把 `--grad-page` 挂到 `.app` 而不是 body——本轮没做，因为用户看过的正是落地页渐变+粒子。
