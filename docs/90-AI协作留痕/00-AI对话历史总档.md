## 0. 先读这段：这份文档解决什么问题

赛事要求提交"AI 对话历史导出的 Prompt 历史快照"，难点有两层：

1. **导出**：要把散落在会话窗口里的交互，变成可提交、可检索、可核验的文件；
2. **证明**：要证明这些不是事后编的，而是**真实发生过的**，且能看出"你是如何驾驭 AI 的"，不只是"AI 帮你写了什么"。

本文件用**证据台账 + 三要素检查 + 追加机制**回应这两层。§5 会明确写出现在还缺什么——不遮掩。

## 2. 导出方案：为什么是"三重证据"而不是一个文件

### 2.1 三条证据链分工

不同形态的证据能证明的东西不同，不能互相替代，所以三条都要有：

| 形态 | 能证明什么 | **不能**证明什么 | 产生时机 | 落地位置 |
| --- | --- | --- | --- | --- |
| **Markdown 原文快照** | 提问原文、AI 输出要点、我的判断与否决、验证命令与结果 | 不能证明"对话真实发生过"（可以事后编） | 每完成一条链当场写 | `docs/90-AI协作留痕/0X-*.md` |
| **会话截图** | 对话真实存在、界面上有输入框与回复、时间可见 | 不能证明我的判断过程 | 每轮关键交互后立即截 | `docs/90-AI协作留痕/evidence/` |
| **录屏** | 连续交互过程，能看出"改一句 Prompt、看结果、再改"的迭代节奏 | 覆盖不全，体积大 | 核心 Bug 修复、核心模块生成时 | 剪辑进 5–8 分钟演示视频，另存原始文件 |

> **优先尝试直接导出**：若所用 AI 工具的新版本支持导出会话，应优先导出完整会话文件（JSON/Markdown）并归档到 `evidence/`，本方案作为兜底。赛事原文明确"如果 AI 工具不支持导出，可以截图或者录屏"，截图是被认可的形态。

### 2.2 截图规范（缺一条就失去证据效力）

| 项 | 要求 |
| --- | --- |
| 命名 | `AI-<链编号>-<序号>-<YYYYMMDD-HHMM>.png`，例：`AI-D-03-20261107-1742.png` |
| 内容 | 必须同时可见 ①我的输入框内容 ②AI 的回复 ③时间或会话标识 |
| 颗粒度 | 每条链 ≥ 3 张：提问、AI 给方案、修复后验证 |
| 隐私遮挡 | 截图前遮挡：API Key/PAT、手机号、真实姓名学号、他人隐私信息 |
| 禁止 | 只截 AI 输出的成品、截掉自己的提问、用 PS 修改内容 |

### 2.3 录屏规范

| 项 | 要求 |
| --- | --- |
| 用途 | 剪辑进演示视频的"≥2 分钟 AI 协同过程复现"片段 |
| 内容 | 必须拍到：输入 Prompt 的完整过程、AI 输出的滚动、我指出问题并追问、最终验证 |
| 分辨率 | 1920×1080，与视频一致 |
| 原始文件 | 保留未剪辑版本，作为原始证据备查 |

## 6.5 每条链的固定 8 段结构
