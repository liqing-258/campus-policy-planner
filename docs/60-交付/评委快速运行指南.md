# 评委快速运行指南

> 目标：**5 分钟内把系统跑起来并看到效果**。不需要装 Python、不需要装数据库、不需要联网（问答除外）。

---

## 一、拿到程序

交付包里应有这几样（缺一样就跑不起来）：

```
知校校园政策助手.exe      ← 主程序，109 MB，双击就用
data/app.db              ← 演示数据库（18 份政策 + 演示记录），别删
启动_知校.bat             ← 双击这个
启动_知校_不打开浏览器.bat
重置演示数据.bat
查看_访问地址.bat
使用说明.txt
.env.example             ← 配置模板（可选）
```

**不要**把 exe 单独复制到别处——`data/` 必须和它同级。

---

## 二、启动（10 秒）

1. 双击 **`启动_知校.bat`**；
2. 会出现一个黑色窗口，等 3–5 秒，浏览器自动打开 `http://127.0.0.1:5000`；
3. 看到落地页（系统名 + 一句话 + 「开启系统」+ 知识库规模）就成功了。

> 浏览器没自动打开？双击 `启动_知校_不打开浏览器.bat`，再手动访问 `http://127.0.0.1:5000`。
> 端口 5000 被占用时：`知校校园政策助手.exe --port 5001`。

**关掉那个黑色窗口 = 停止服务。** 数据不会丢（在 `data/app.db` 里）。

---

## 三、登录

点落地页的「开启系统」，输入：

| 账号 | 口令 | 能用什么 |
| --- | --- | --- |
| `student` | `student123` | 提问、填画像、做资格匹配、生成计划、看日历、收藏 |
| `admin` | `admin123` | 上传/维护政策、复核条件、数据中心、反馈管理 |

已经登录过的话，落地页按钮下面有一行「**换个账号登录**」。

## 四、看四个核心功能（建议顺序）

| # | 做什么 | 在哪 | 看什么 |
| --- | --- | --- | --- |
| 1 | **问一句政策问题** | 左侧「智能问答」 | 回答带 **引用编号**，点引用能跳到原文片段；下方给 3 条「继续追问」（**点一下只填进输入框，再点发送**） |
| 2 | **做一次资格匹配** | 左侧「资格匹配」 | 选政策 → 填画像 → 开始匹配；结果分 **符合 / 不符合 / 无法判定**，每条都写清依据 |
| 3 | **生成一份办事计划** | 匹配结果页点「生成计划草稿」→ 草稿卡里点「确认并写入任务中心（N 项）」 | 自动列出要办的事、材料、截止时间；缺年份这类信息会**明说需要人工确认** |
| 4 | **看管理员数据中心** | 用 `admin` 登录 → 「数据中心」 | 四张指标卡、画像与主题分析、关键词词云、24 小时提问分布、明细表 |

---

## 五、三个"这是正常现象"的说明

1. **回答只有原文、没有归纳**：`.env` 里没配模型密钥，系统自动进**降级模式**（界面顶部有提示）。
   这是设计好的降级路径，不是故障。
2. **匹配页只有 3 份政策**：只有"条件已经人工复核过"的政策才会出现在匹配页。
   其余政策是待复核状态——**未复核的条件不参与判定**，这是刻意设计。
3. **数据中心某些数字很小**：演示库里的记录量本来就不大（49 次匹配 / 174 条提问）。

## 六、停止与重置

| 想做的事 | 怎么做 |
| --- | --- |
| 停止服务 | 关掉那个黑色窗口 |
| 恢复出厂演示数据 | 双击 `重置演示数据.bat`（旧库会改名备份，不删） |
| 换端口 | `知校校园政策助手.exe --port 5001` |

---

## 七、想在另一台电脑上访问

默认只监听本机（`127.0.0.1`），**别的电脑打不开**。要给别人看：

```bat
知校校园政策助手.exe --host 0.0.0.0 --no-browser
```

然后让对方访问 `http://<你的电脑IP>:5000`，并在 Windows 防火墙放行 5000 端口。

---

## 八、常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 双击 bat 闪一下就没了 | 端口被占用，或 exe 被杀软隔离。用 `--port 5001` 重试 |
| 页面打不开但窗口在 | 地址对不对（`http://127.0.0.1:5000`）；换浏览器试；看窗口里打印的实际端口 |
| 登录提示用户名或密码错误 | 账号是 `student` / `admin`（不是邮箱）；口令见上表 |
| 提问一直转圈 | 模型服务不可达（网络/欠费）。等它超时后会给出明确提示，不会静默卡死 |
| 匹配页下拉是空的 | 说明当前没有"条件已复核"的政策；用 `admin` 进左侧「**规则管理**」复核后再看 |
